# PRD 落地拆解

## 产品边界

小页匠 V2.0 仅实现 PDF 专项处理能力：页面截取、多 PDF 合并、离线 OCR 识别、OCR 结果 Word 导出。所有处理均在本机完成，客户端仅访问 `127.0.0.1` 本地服务。

## 当前工程已建立

- Electron 主进程：应用窗口、文件选择、保存对话框、本地服务拉起与退出回收。
- Vue3 客户端：功能中心、PDF 截取、PDF 合并、OCR 识别页面骨架。
- FastAPI 本地服务：健康检查、任务互斥、PDF 截取、PDF 合并、OCR 接口占位。
- PDF 核心处理：截取与合并服务层已按 PyMuPDF 实现。
