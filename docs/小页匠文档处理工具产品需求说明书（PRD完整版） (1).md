## 1. 文档说明

### 1.1 文档目的

本文档为《小页匠》桌面文档处理工具正式产品需求说明书，用于明确产品定位、业务范围、功能需求、交互逻辑、技术架构约束、异常处理及交付标准，是项目研发、UI设计、测试验收、项目交付的唯一正式依据，所有开发及测试工作均以本文档内容为准。

### 1.2 适用范围

本次V2.0版本仅落地PDF专项处理功能，包含PDF页面截取、多PDF文件合并、PDF离线OCR文字识别、OCR结果Word导出。所有功能均为本地离线处理，无云端数据上传、无网络依赖，不涉及在线服务能力。

### 1.3 术语定义

|术语|释义|
|---|---|
|C/S架构|客户端/本地服务架构，本产品分为Electron桌面客户端进程、Python本地文件处理服务双进程，全程本地交互|
|Electron|桌面客户端外壳框架，实现跨平台桌面应用封装，支撑Vue3页面运行|
|Vue3|前端界面开发框架，负责产品页面渲染、用户交互、参数处理、接口调用|
|FastAPI|Python轻量本地接口服务框架，提供PDF处理、OCR识别相关本地接口能力|
|OCR|光学字符识别技术，用于提取扫描版、图片型PDF中的文字内容|
## 2. 产品整体概述

### 2.1 产品定位

小页匠是一款轻量化、纯本地离线桌面PDF处理工具，面向个人普通用户，提供极简的PDF页面编辑、文件合并、图文文字识别能力。产品主打无广告、无云端上传、操作简单、轻量化运行，架构高度可扩展，可后续拓展多类型文档处理功能。

### 2.2 核心目标

1. 实现PDF精准页面截取、多文件有序合并，满足用户基础PDF编辑需求；

2. 实现全离线PDF-OCR识别，支持文本预览与标准Word文档本地导出；

3. 采用Electron+Vue3跨平台架构，适配主流桌面操作系统，保证运行稳定；

4. 全流程本地处理，杜绝用户文件及隐私数据泄露风险；

5. 模块化架构设计，预留扩展接口，支持后续迭代新增文档处理功能。

### 2.3 功能模块划分

产品采用模块化低耦合设计，V2.0版本仅包含**PDF处理主模块**，所有PDF相关功能统一归属该模块。系统架构预留独立模块入口，后续新增Word、图片、TXT等文档处理功能时，可独立新增模块，无需改动现有PDF模块核心代码与逻辑。

## 3. 产品架构与技术路线

### 3.1 整体架构模式

采用**C/S客户端+本地服务双进程架构**，全程离线运行，无外网网络请求，所有数据处理均在用户本地设备完成。

1. 客户端进程：Electron承载Vue3前端项目，负责界面展示、用户交互、文件选择、参数校验、结果预览、操作指令下发；

2. 本地处理服务进程：Python+FastAPI搭建本地轻量服务，负责PDF文件解析、页面处理、OCR识别、Word文档生成；

3. 进程通信：基于本地回环地址HTTP协议通信，仅支持本地访问，禁止外网访问，保障本地服务安全。

### 3.2 完整技术栈选型

#### 3.2.1 桌面客户端层

1. 外壳框架：Electron，实现Windows、macOS跨平台桌面应用封装；

2. 核心框架：Vue3（Composition API），轻量化、高性能页面开发；

3. 构建工具：Vite，实现快速热更新、高效打包构建；

4. 辅助工具：Vue-Router页面路由管理、Pinia全局状态管理、Element Plus UI组件库、Axios接口请求封装。

#### 3.2.2 本地处理服务层

1. 服务框架：Python + FastAPI，搭建高性能本地接口服务；

2. PDF处理核心：PyMuPDF，实现PDF页面读取、精准截取、多文件合并；

3. OCR识别核心：离线版PaddleOCR，适配扫描PDF、图片型PDF文字提取；

4. 文档导出工具：python-docx，生成标准docx格式Word文档。

#### 3.2.3 打包部署工具

1. 前端打包：Vite编译静态资源，electron-builder打包桌面客户端程序；

2. 服务打包：PyInstaller将Python程序编译为独立可执行文件，无需用户配置环境；

3. 整体封装：整合客户端、服务程序、内置依赖，生成一体化安装包。

### 3.3 整体运行流程

1. 用户启动桌面端程序，Electron初始化并自动加载Vue3前端界面；

2. 客户端后台静默启动Python FastAPI本地服务，无弹窗、无黑窗口；

3. 用户完成文件导入、参数配置等操作，前端校验参数合法性后，通过本地HTTP请求调用对应接口；

4. Python服务接收请求，执行PDF截取、合并、OCR识别等对应处理逻辑；

5. 处理完成后，服务端返回状态码、处理文本或生成文件路径；

6. 前端接收返回数据，完成界面预览、进度更新、本地保存等操作；

7. 用户关闭客户端时，程序自动终止Python服务子进程，释放设备资源。

## 4. 全局通用规则

以下规则统一适用于PDF模块下所有功能，为系统全局约束，所有功能开发需严格遵循。

1. **文件导入规则**：仅支持.pdf后缀标准PDF文件，支持本地文件点击选择、拖拽导入两种方式；导入非法格式、损坏文件、空文件时，界面弹出标准化错误提示，禁止继续执行操作。

2. **运行状态规则**：文件解析、参数校验、任务处理、文件导出全流程展示加载状态，支持进度可视化；支持用户手动终止正在执行的处理任务。

3. **存储规则**：所有导出文件均唤起本地保存路径选择窗口，由用户自主选择保存目录，程序不强制固定存储路径，不自动留存用户文件。

4. **任务互斥规则**：同一时间仅允许执行一项文件处理任务，任务运行期间，其他所有功能按钮置灰禁用，防止多任务冲突导致程序异常。

5. **加密文件规则**：自动检测加密PDF、权限受限PDF（禁止复制、编辑、打印），检测异常后直接终止任务，弹出对应提示，不执行无效处理逻辑。

6. **离线运行规则**：程序所有功能无需联网，所有运行依赖、算法模型、资源文件均内置在安装包内，全程离线可用，无静默联网行为。

7. **临时文件规则**：任务运行产生的缓存、临时文件，在任务结束、程序关闭后自动清理，不占用用户本地存储空间。

## 5. 核心功能详细需求

本章节核心功能分为两大模块：PDF工具核心模块、系统设置模块。将所有PDF处理相关功能统一聚类管理，结构清晰、职责分明；同时全局支持后台任务消息提示能力，提升用户操作体验。

### 5.1 PDF工具核心模块

本模块聚合所有PDF业务处理能力，包含：PDF页面截取、PDF文件合并、PDF离线OCR识别，所有功能支持后台静默处理，不阻塞软件界面操作，任务完成后统一触发系统消息提示。

#### 5.1.1 PDF页面截取功能

##### 5.1.1.1 功能描述

针对单个PDF源文件，根据用户自主选定的页面范围，精准提取指定页面，生成全新的独立PDF文件并支持本地导出，完整保留原页面排版、内容、样式。

##### 5.1.1.2 操作流程

1. 文件导入：用户点击选择或拖拽单个PDF文件，前端完成文件加载，展示文件基础信息（总页数、文件大小），并渲染页面预览区域；

2. 页面选择（双模式可选，用户自由切换）：

模式一：手动页码输入模式。支持单页码（如3）、连续页码（如1-6）、不连续多页码（如1,3,5,7）输入；前端实时校验输入内容，非法字符、页码超出文档总页数、格式错误时，即时给出局部文字提示，禁止提交任务；

模式二：可视化缩略图选择模式。展示PDF全部页面缩略图，支持鼠标单选、多选页面，选中页面高亮标记，可直观查看所选页面内容；

3. 执行截取：用户完成页面选择后，点击「开始截取」按钮，前端校验合规后向本地服务发起处理请求；

4. 文件导出：处理完成后，自动唤起本地文件保存窗口，用户选定保存路径与文件名后，完成新PDF文件保存。

##### 5.1.1.3 功能约束

1. 仅支持单份PDF源文件截取，不支持多文件混合页面截取；

2. 未选择任何有效页面时，执行按钮置灰禁用，给出文字提示，无法发起任务；

3. 输出文件固定为PDF格式，不修改原页面内容、排版、分辨率；

4. 仅有效页码可被截取，自动过滤重复页码、无效页码。

#### 5.1.2 PDF合并功能

##### 5.1.2.1 功能描述

支持导入多份独立PDF文件，用户可自主调整文件排序顺序，系统按照最终排序依次拼接所有文件页面，合并生成一份完整的全新PDF文件，支持本地导出保存。

##### 5.1.2.2 操作流程

1. 文件导入：用户批量选择或拖拽多个PDF文件，文件按导入顺序展示在列表中，列表展示文件名、文件大小信息；

2. 顺序调整：支持对列表内单个文件进行上移、下移、删除操作，支持一键清空全部文件，用户可自定义最终合并顺序；

3. 执行合并：确认文件顺序无误后，点击「开始合并」按钮，前端校验文件数量合规后发起处理请求；

4. 文件导出：合并任务完成后，唤起本地保存窗口，用户自定义保存路径与文件名，完成合并文件保存。

##### 5.1.2.3 功能约束

1. 导入有效PDF文件数量少于2个时，合并按钮置灰禁用，给出对应提示；

2. 合并过程完整保留所有源文件的页面内容、排版、样式、分辨率，不压缩、不篡改原始内容；

3. 输出文件固定为PDF格式；

4. 自动过滤重复导入的相同文件，规避无效合并任务。

#### 5.1.3 PDF OCR识别功能

##### 5.1.3.1 功能描述

针对普通可复制PDF、扫描版PDF、图片内嵌式PDF，执行全离线OCR文字识别，精准提取文档内全部文本内容；支持界面实时预览识别结果，支持将全部识别内容导出为标准docx格式Word文档并保存至本地。

##### 5.1.3.2 操作流程

1. 文件导入：用户选择或拖拽单个PDF文件，完成文件加载与解析；

2. 启动识别：点击「开始OCR识别」按钮，前端发起请求，后台执行PDF页面拆分、图文识别、文本整合逻辑；

3. 结果预览：识别任务完成后，界面专属文本展示区渲染全部识别内容，支持文本全选、复制、滚动查看；

4. 文档导出：用户点击「导出Word」按钮，唤起本地保存窗口，选定路径后生成并保存docx格式文档。

##### 5.1.3.3 功能约束

1. 适配常规电子PDF、扫描纸质PDF、图片型PDF识别场景；

2. V2.0基础版本仅提取纯文本内容，不还原原文件复杂排版、表格、图片、特殊格式样式；

3. 界面展示为纯文本格式，导出文件固定为标准docx Word格式；

4. 加密、权限受限、损坏无法解析的PDF，识别任务直接终止，弹出异常提示。

#### 5.4.1 功能描述

客户端提供独立系统设置功能，支持用户自定义软件基础运行配置与视觉配置，所有配置项本地持久化保存，重启软件自动生效记忆，无需重复设置。设置模块包含四大核心配置项：开机启动设置、主题风格设置、语言设置、默认存储路径设置，整体交互简洁、配置即时生效，严格遵循苹果HIG设计规范。

顶部导航栏右上角固定「设置」图标入口，点击唤起设置弹窗；设置弹窗为全局通用液态玻璃材质，样式、动效、圆角、阴影完全对标苹果原生弹窗规范，不占用主功能页面布局，随时可打开、关闭。

#### 5.4.3 开机启动设置

**功能说明**：支持开启/关闭软件电脑开机自启动能力，适配Windows、macOS双系统。

**配置规则**：默认关闭开机启动；用户手动勾选开启后，设备开机自动后台静默启动本软件，无弹窗骚扰；取消勾选即关闭开机自启权限。

**持久化规则**：配置本地永久保存，重启软件、重启电脑均保留用户设置。

#### 5.4.4 主题风格设置

**功能说明**：提供双主题切换能力，严格遵循苹果HIG深浅色设计规范，适配全局Liquid Glass液态玻璃视觉体系。

**可选主题**：浅色主题（默认）、深色主题，无自定义主题选项。

**切换规则**：用户点击单选切换，**即时生效无需重启软件**，切换过程伴随苹果标准淡入淡出缓动过渡动效；全局所有UI组件、材质、文字、阴影、预览界面同步适配对应主题样式。

**适配要求**：全分辨率兼容，最高支持2K分辨率自适应，双主题下无材质失真、颜色错乱、界面拉伸、文字模糊问题。

**记忆规则**：切换后本地持久化存储，软件重启自动沿用上次主题配置。

#### 5.4.5 语言设置

**功能说明**：支持软件界面展示语言切换，实现界面文字全局同步替换。

**初始版本可选语言**：简体中文（默认）、英文，预留多语言拓展接口，支持后续新增语言包。

**切换规则**：用户选择对应语言后即时生效，界面所有导航文字、按钮文案、提示文案、弹窗文字、功能说明文字全局同步切换，无需重启软件。

**记忆规则**：语言配置本地持久化保存，重启软件自动沿用。

#### 5.4.6 默认存储路径设置

**功能说明**：用户可自定义PDF导出、Word导出文件的默认保存目录，解决每次手动选择路径的操作成本。

**默认规则**：软件初始默认存储路径为系统下载文件夹；用户可手动更换任意本地磁盘文件夹作为默认路径。

**使用规则**：设置完成后，后续所有文件导出默认优先填充该路径，用户可在单次导出时临时修改保存路径，不覆盖默认配置。

**路径校验规则**：自动校验路径有效性、磁盘写入权限、磁盘空间，路径无效或无权限时弹出标准异常提示，不允许保存无效配置。

**记忆规则**：自定义存储路径永久本地保存，重启软件不重置。

#### 5.4.7 通用配置约束

1. 所有设置项修改后即时生效，无延迟、无需重启程序；

2. 所有配置数据仅本地存储，不上传云端，保障用户配置隐私；

3. 设置弹窗样式、交互、动效严格遵循苹果HIG设计规范，适配双主题、2K分辨率；

4. 支持用户随时重置所有设置为软件默认状态。

### 5.3 全局后台任务消息提示功能

#### 5.3.1 功能描述

软件支持**后台任务异步处理 + 任务完成消息弹窗提示**能力。用户发起PDF处理任务后，程序支持后台静默运行任务，用户可自由操作软件其他界面、无需等待；待后台任务执行完成/失败后，客户端自动弹出消息提示，告知用户任务状态，解决等待卡顿、不知道任务是否完成的体验问题。

#### 5.3.2 触发场景

所有PDF处理任务均支持后台消息提示，包含：PDF页面截取任务、PDF文件合并任务、PDF OCR识别任务。

#### 5.3.3 交互规则

1. 异步后台处理：用户发起任务后，任务转入后台运行，界面不锁定、不阻塞，用户可正常切换页面、操作其他功能；

2. 消息弹窗时机：后台任务执行完毕后，无论成功/失败，自动在客户端界面右上角弹出轻量化消息提示；

3. 提示文案规范：任务成功提示「XXX任务执行完成，可前往保存文件」；任务失败提示「XXX任务执行失败，请检查文件或权限后重试」；

4. 弹窗样式：消息提示弹窗遵循苹果HIG极简风格，液态玻璃材质、轻柔动效、自动消失，可手动关闭；

5. 多任务处理：遵循全局任务互斥规则，同一时间仅一个后台任务运行，任务队列依次执行并逐个触发消息提示；

6. 最小化适配：软件窗口最小化状态下，后台任务正常运行，恢复窗口后可正常接收消息提示。

#### 5.3.4 功能约束

1. 消息提示仅客户端内弹窗展示，无系统桌面弹窗、无推送打扰；

2. 所有消息提示无广告、无多余跳转，仅展示任务结果状态；

## 8. 异常处理机制

所有异常场景统一报错逻辑与提示文案，区分局部提示与全局弹窗提示：

1. **文件类异常**：文件不存在、文件损坏、格式错误、空文件 → 全局弹窗提示：「文件异常，请重新选择有效PDF文件」；

2. **权限类异常**：PDF加密、权限受限禁止编辑/复制 → 全局弹窗提示：「该文件已加密/受限，无法处理」；

3. **参数类异常**：页码格式错误、页码超出范围、文件数量不足 → 页面局部文字提示，无全局弹窗；

4.**服务类异常**：本地Python服务启动失败、接口超时、服务中断 → 全局弹窗提示：「本地服务异常，请重启程序重试」；

5. **存储类异常**：设备无写入权限、保存路径无效、磁盘空间不足 → 全局弹窗提示：「保存失败，请更换保存路径或检查磁盘空间」。
